# AI Document Classifier

A machine learning project that classifies text documents into different categories.

## Categories

* Sports
* Technology
* Education
* Health
* Entertainment

## Technologies Used

* Python
* Scikit-learn
* Tkinter
* TF-IDF Vectorizer
* Naive Bayes Algorithm

## Features

* GUI-based application
* Multi-category text classification
* Accuracy display
* Saved machine learning model

## How to Run

1. Open terminal
2. Run:

```bash
python app.py
```
